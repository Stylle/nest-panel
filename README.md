# 栖页 · Nest Panel

轻量、自托管的单用户导航面板。Go 内嵌 Vue 前端，SQLite 保存配置，一个容器、一个数据目录。支持 Sun-Panel v1 JSON 导入，图标和背景随配置迁移。

## 最简部署

```yaml
services:
  nest-panel:
    image: stylle/nest-panel:latest
    container_name: nest-panel
    restart: unless-stopped
    ports:
      - "28189:8080"
    volumes:
      - ./data:/data
```

保存为 `compose.yaml`，执行 `docker compose up -d`，访问 `http://你的服务器:28189`。首次访问创建唯一管理员；密码至少12位，含大小写字母、数字和符号，最多72个UTF-8字节。没有默认密码、注册和多用户管理。首次初始化请在可信网络完成，公网使用HTTPS反向代理。

支持 `linux/amd64` 和 `linux/arm64`。固定版本使用 `stylle/nest-panel:0.2.4`；`latest` 跟随稳定版。无需填写环境变量、数据库或第三方密钥。

镜像启动时自动准备普通宿主机挂载目录，然后降权为 UID 10001 运行，不需要额外初始化容器。NFS root-squash、只读挂载或手动指定非root `user:` 时仍须保证运行用户有写权限；不会递归修改其他目录权限。升级不要删除 `/data`。

## 网站与分组

- 添加地址，离开地址输入框后自动获取标题和图标；也可点击「自动获取」。标题、描述、图标可以手动修改，支持逐网站上传图标，无公共图库。
- 抓取失败不会阻止保存。标题可自行填写，图标使用内置默认图标；在「网站管理 → 补全图标」可以依次补抓缺失图标并随时停止。
- 点击分组标题旁的「整理」，拖动网站排序；编辑网站可更改所属分组；触摸设备长按后拖动。「分组管理」拖动把手调整分组顺序。
- 搜索标题、域名和描述。网站在新标签页打开，没有内外网切换，每个网站只有一个地址。

## 主题外观

「主题外观」可独立选择顶部或左侧分类，搭配玻璃卡片、悬浮图标或横向卡片，以及白色或黑色遮罩。站点标签大小、网格行距和列距可分别调节。右上角可切换浅色、深色或跟随系统，显示模式存于当前设备。浅色和深色分别保存遮罩强度。遮罩强度同步应用到导航、站点卡片及设置界面的主要底色。顶部分类可横向滚动，也可用「更多」选择分组；左侧分类可独立纵向滚动。管理员可在每个分组标题旁添加网址。

主题修改实时预览，点击「保存主题」才持久化。背景API支持图床随机图等直接返回图片或重定向到图片的HTTP(S)接口，不解析JSON；点击「获取并应用」会立即保存API来源和当前缓存图片，「刷新背景」可换一张。不开后台轮询，访客仅访问缓存图片，不会取得原始带Token地址。来源只进入完整加密备份，普通配置导出只包含当前缓存图片。移除 API 背景会同时清除来源和当前背景，切回本地上传也可继续使用。全站使用管理员保存的主题，语言仅记住在当前设备。图片最大8MB、背景最大1200万像素，自动缩小至最长边1920px；普通图标最大400万像素、输出最长边128px。图片重新编码为PNG，去除元数据，不保留动画；SVG不直接接受，失败时使用默认图标。支持常见PNG/JPEG/WebP/GIF以及内嵌PNG或常见24/32位未压缩位图的ICO，其他ICO变体可能无法获取。

## 公开访问与安全

「访问安全 → 允许公开访问」默认关闭。开启后，访客可查看未隐藏分组及其网址、描述、图标和公共背景，不要加入包含密码、Token或私人内容的链接。配置、备份、容器发现和账户修改仍只允许管理员访问。

登录会话固定有效七天，刷新和正常重启不会使其失效。退出登录立即撤销当前会话；修改账户密码或恢复完整备份会撤销所有会话，旧密码立即失效。密码使用bcrypt，登录有失败限流，不信任客户端自行填写的转发IP；反向代理后的客户端可能共享限流额度。

元数据由自己的服务器抓取，不会把私人网址提交给公共图标服务。需要服务器能够访问目标站点；管理员填写的局域网HTTP(S)地址允许获取，环回、链路本地、云元数据地址及危险协议会被阻止，DNS和重定向逐次检查。无远端HTML执行、无任意JS/CSS注入。内容安全策略限制脚本和图片来源。

## Sun-Panel 导入

打开「网站管理 → 选择配置文件」，导入 `Sun-Panel-Config`、`version: 1` 格式的 JSON（通常为 `.sun-panel.json`）。先预览分组、网站、图片和提示，再选择合并或替换。合并按网址去重；替换会提示确认。其他版本或格式会拒绝导入，不会清空现有配置。

- 保留分组、网站名称、描述和排序。普通 `url` 优先；只有它为空才使用 `lanUrl`，不导入双地址切换。
- 非HTTP(S)地址和无可用网址的卡片会被跳过。
- 旧版 Sun-Panel JSON 不包含实际上传的图片。可用的Base64图片会导入，上传文件路径、远端图片路径和图标库名称不会假装已经迁移；缺失时用默认图标，再按需补抓。
- 不导入账号、脚本、个性化代码、系统小组件或Docker控制配置。Sun-Panel v2 ZIP包不属于本版支持的JSON格式。

本程序配置导出同时包含主题和图片；普通导入不会改变当前公开开关或管理员账户。导入JSON最大48MB、最多200分组/5000网站，图片合计32MB；完整加密备份文件最大64MB。存储图片总量最多128MB，内容哈希去重；未被使用的历史图片不进入导出/备份，完整恢复会清理这些历史图片。

## Docker 自动发现（可选）

在同一个服务的 `volumes` 下增加：

```yaml
      - /var/run/docker.sock:/var/run/docker.sock:ro
```

重新创建容器，在「容器发现」填写生成访问链接的主机IP或域名，扫描后检查地址，选择目标分组并添加。只读取当前Docker宿主机运行中容器的TCP映射端口；无端口、停止的容器不会添加。多端口容器可能包含非网页服务，请确认后选择；不会自动猜测反向代理域名或HTTPS。重复扫描会标记已有网址。

可在目标容器添加可选标签：

```yaml
labels:
  nest-panel.title: "我的服务"
  nest-panel.url: "https://service.example.com"
  nest-panel.hide: "false"
```

`hide: "true"` 排除容器。容器详情仅管理员可见。程序只调用读取容器列表的固定GET接口，不实现启动/停止/exec。**Socket的只读挂载并不等于Docker API只读授权**，不需要发现功能就不要挂载；不要把未认证Docker TCP端口暴露到网络。自定义Socket路径可通过 `DOCKER_SOCKET` 设置。Docker Desktop的Windows本地源码服务不支持Unix Socket发现，请在Linux容器中使用。

## 备份、恢复与升级

「备份恢复」有两种文件：

1. **配置JSON**：网站、分组、主题、Base64图标和背景，不含管理员密码。导入入口在网站管理，支持合并/替换。它是明文，分享前检查地址和描述。
2. **完整加密备份**：以上内容加管理员账户密码哈希，使用AES-256-GCM和PBKDF2-SHA256（210000次）加密。自行设置至少12位备份密码，遗失无法恢复。

在其他设备新部署后，创建临时管理员，选择完整备份并填写备份密码；确认后事务式恢复全部内容。恢复失败保留原数据，成功后所有会话失效，使用备份中的原账户密码重新登录。没有额外“我已备份”勾选项，仅在恢复时确认。会话不进入备份。

升级前下载完整备份，然后：

```sh
docker compose pull
docker compose up -d
```

保留原数据挂载，或停容器后备份整个数据目录（不要在写入时只复制 `panel.db`，SQLite还有WAL文件）。

## 占用与开发

没有后台网站轮询、监控探针、Node运行时、外部数据库或动画背景。元数据请求最多并发3个，顺序补全图标；网页/图片响应有大小和时间上限。图片独立按需加载，配置接口不返回Base64。静态资源支持长期缓存，图标使用私有缓存，关闭公开访问后旧浏览器已下载的内容无法撤回。

默认Go软内存目标96MiB（不是容器硬限制），大图、批量导入与加密备份会短时使用更多内存。需要严格资源限制时先按自己的网站/图片数量测量，不建议给大备份设置过低的硬限制。镜像支持 `GOMEMLIMIT`、`GOGC`、`LISTEN_ADDR`（默认`:8080`）和`DATA_DIR`（默认`/data`）覆盖。

首版在Linux/amd64、1 CPU配额的本地Docker测试中，镜像未压缩约35MB；空实例空闲约5MiB，装入1200个网站、20个分组、缓存背景后空闲约11MiB（Docker stats口径），CPU空闲样本0.00%。100次完整配置请求平均约25ms。前端JS预压缩后约147KB，页面不打包全部图片。以上是测试环境样本，非所有硬件保证，也不是导入/加密时的峰值。单份网站文字配置最大3MB，图片另行保存。

开发需要Go 1.26.11+、Node.js 24+：

```sh
cd frontend
npm ci
npm run build
cd ..
go test ./...
go vet ./...
go run .
```

`GET /healthz` 提供健康检查。前端开发 `npm run dev` 代理到 `127.0.0.1:28189`，另行设置后端监听地址。MIT开源；导入格式参考Sun-Panel，本项目为独立实现，详见第三方说明。
