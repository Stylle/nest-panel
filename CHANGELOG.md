# Changelog

## 0.2.0

- 顶部和左侧分类可搭配玻璃卡片、悬浮图标或横向卡片。新增站点标签大小、行列间距、黑白底色强度与日期时间选项。
- 更新手机分组选择器和后台菜单。添加网址与整理操作放到分组标题旁。
- 支持公开访问时隐藏分组。访客无法读取隐藏分组的专属图标；导入与备份保留隐藏标记。
- 移除 API 背景时同时清除当前壁纸。页脚显示运行版本。

## 0.1.0

- Single-user navigation with optional public read-only access, seven-day persistent sessions, password change and session revocation.
- Independent graphite/ivory/ocean/system palettes, card/grid layouts, original/tiled icons and three density levels.
- Local or API background images, opacity and blur controls; cached API backgrounds keep source URLs out of public responses and ordinary exports.
- Website metadata/icon fetching, editable titles, bundled fallback icons, local per-site image upload, search and drag sorting.
- Sun-Panel v1 JSON preview, ordered groups, one-address migration, merge deduplication and replace confirmation.
- Self-contained Base64 configuration export and encrypted complete backup with atomic cross-instance restoration.
- Optional local Docker discovery with candidate review, editable addresses, group selection and label hints.
- One container, SQLite, non-root application process, bounded image processing, lazy icons and precompressed static assets.
